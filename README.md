# Puente de Mando PER

App de estudio del examen teórico del PER (convocatoria de noviembre de 2026): temario, tests de convocatorias oficiales, simulacros y módulos interactivos. Se instala en el móvil como web app y funciona sin conexión.

`python3 tools/build_web.py` genera la web en `dist/`. Cada push a `main` la publica en GitHub Pages.

Proyecto personal de estudio. Comprueba siempre la normativa vigente en las fuentes oficiales.
